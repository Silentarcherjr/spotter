# Final end-to-end live test — approximately 45 minutes

Run this once after construction is complete; this document does not itself start a stream. Use only the two authorized test channels, the licensed IRL clip, a synthetic TEST-ONLY QR and the explicitly SIMULATED voice file. Set up both local Spotter instances, distinct OBS profiles and the crew link before the timed run. Confirm both Twitch authorizations, both channels' raid policies and a separate viewer on the emitting channel for each raid. Save authorized evidence to `data/takes/`; never capture keys, stream settings, private chat terms or unrelated windows. The public program must never contain the private dashboard. Enable VOD on the primary before starting so marker creation can be checked.

**Safe abort at any step:** manually select **Privacy** in the relevant OBS. Stop each transmission from its own OBS if protection, player output or account identity is uncertain. Stop the private evidence recording and note the result; do not retry invisibly or claim a pass. Keep secrets and QR content out of notes.

| 0–5 min | With both outputs stopped, run `npm run dev` for the main instance. Put a clean, QR-free source in Main. Run `npm run golive:check` or press **Re-check** in the private dashboard. Unavailable vision remains amber and must be reviewed; no color is a guarantee. Abort if red is present. |
| 5–8 min | Start only the primary stream from its OBS; open its Twitch player and begin an isolated, silent local recording of the dashboard and player. Start the IRL clip in Main. | Player shows the intended public clip and SIMULATED badge where applicable; no private dashboard on air. |

| 13–15 min | Press **Dismiss privacy action**. Record the click and both OBS and player as Main returns. | The exact previous scene returns. Do not expose actual private content. |

After several protected appearances, press **Dismiss** once as a positive control, then allow automatic rearming. | Detector triggers Privacy and marker. The fictitious QR is visible in the intentional control and subsequent protected appearances are hidden in the recorded player. Review every relevant recorded frame later; this is a finite test, not a guarantee. |

Wait for both live statuses and the relay suggestion or press **Request tag out**. Click **Approve** once. Record approval, Twitch countdown and EventSub confirmation, plus the receiver's **Covering for** overlay in its actual player. | Outbound raid is confirmed by EventSub and the receiver overlay uses the real display name. | 36–41 min | Place the separate viewer on the secondary channel, confirm the primary is live and ready, then request and approve **Tag back** from the companion side. Record the companion click, countdown and return confirmation. | EventSub confirms the return to the primary channel; no automatic raid occurs without a click. |
| 41–45 min | Stop both streams from their respective OBS windows; stop and save evidence. Return Main to a clean QR-free source and run **Re-check** / `npm run golive:check` again. Record the final status and end-of-stream report. | Both outputs stopped and final check has no red; review and retain any amber findings. Restore temporary sources/profiles and verify no stream is running. |

After the session, inspect the recorded Twitch player control and protected windows frame by frame with `npm run qr:analyze-take -- <local-movie>` using the recorder's measured crop. A successful test applies only to the recorded scenario; small, blurred, occluded or brief codes can be missed. Never decode, save or publish QR payloads, location guesses, private terms or secrets. Update the checklist and codex log with observed results and failures, not expected results.
